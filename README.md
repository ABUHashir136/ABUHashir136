### 📂 Featured Projects & Architecture

I believe in building software that solves real-world problems. Here is a glimpse of what I develop:

#### 1. 🤖 AI Prompt Marketplace 
A full-stack web application featuring dynamic prompt cards, category listings, and top creator leaderboards. 
- **Tech:** PHP, SQL, Tailwind CSS
- **Features:** Optimized dynamic hero sections, complex SQL foreign key constraints for creator-prompt mapping, and automated meta tag generation.

#### 2. 📊 Business Transaction Ledger System
A secure, role-based financial ledger designed for business workflow efficiency.
- **Tech:** PHP, MySQL, JavaScript
- **Features:** Role-dependent UI headers (Admin vs. Staff), automated transaction calculations, custom database tables (`company_ledger`), and custom keyboard shortcut listeners (F2, F3, F4) for rapid data entry.

#### 3. 👁️ Clinical Consultation PWA
A Progressive Web App tailored for medical consultation workflows.
- **Tech:** JS, Service Workers, PHP
- **Features:** Offline caching via service workers, resolution of CORS fetch policy errors, and dynamic clinical dropdown data structures.
